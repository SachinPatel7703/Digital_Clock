This is a simple and responsive Digital Clock built using HTML, CSS, and JavaScript. It displays the current time in real-time with a clear, modern design. The clock automatically updates every second and can be used as a web widget for any personal or educational project.

Features:

Shows hours, minutes, and seconds

Updates in real-time using JavaScript

Clean and responsive design for all screen sizes

Easy to customize colors and styles

Tech Stack:

HTML for structure

CSS for styling

JavaScript for real-time functionality

Usage:

Open index.html in any web browser

See the clock running live

Customize style via style.css if needed

Purpose:
A beginner-friendly project to practice front-end development, DOM manipulation, and real-time updates. Perfect for learning how JavaScript interacts with HTML and CSS
